# Third-party 3D assets

None. Everything the world draws (island, tree, grass, flowers, rocks, water, clouds, every
prop and landmark, the birds, bees, butterflies and fireflies) is generated in code under
`src/world/`: props and creatures are built from primitives by `src/world/scene/kit.ts`.

When a model is added here (self-hosted, compressed GLB, never hot-linked), record it in
this table. Only CC0, MIT and similarly permissive licences: nothing that needs a paid
licence or an attribution we cannot give.
